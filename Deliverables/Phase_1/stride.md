## Stride

## Stride Threat Matrix

| ID | DFD Element | STRIDE | Threat Description | Threat Agent | Asset | Risk Level |
|---|---|---|---|---|---|---|
| TH-01 | Authentication Process (POST `/users/login`) | **Spoofing** | An attacker submits forged credentials or replays a captured JWT token to impersonate a legitimate user. | External attacker / malicious authenticated user | User session; all user data accessible under the impersonated identity | **High (16)** |
| TH-02 | Authentication Process (POST `/users/login`) | **Tampering** | An attacker intercepts a JWT on the unencrypted HTTP channel and modifies the payload, for example the role field, before re-sending it, exploiting inconsistent JWT secrets between sign and verify modules. | Man-in-the-middle / insider | JWT integrity; user role and identity | **High (15)** |
| TH-03 | Authentication Process (POST `/users/login`) | **Information Disclosure** | Login error responses or server-side `console.log` statements reveal whether an email is registered, internal error details, or stack traces, aiding attacker enumeration. | External attacker | User account existence; internal system details | **High (15)** |
| TH-04 | Authentication Process (POST `/users/login`) | **Denial of Service** | No rate limiting on POST `/users/login` allows unlimited automated requests, enabling brute-force or flooding attacks that exhaust server resources. | External attacker | Platform availability; legitimate user access | **High (16)** |
| TH-05 | User Management Process (POST `/users`) | **Spoofing** | An attacker registers a new account with an email address impersonating a legitimate manager or dietician, gaining trust-based access to operations. | External attacker | User registry; operational trust | **Medium High (12)** |
| TH-06 | User Management Process (POST/PUT `/users`) | **Tampering** | An authenticated user sends a PUT `/users/:id` request with a modified role field to self-elevate their role, exploiting missing server-side role validation. | Authenticated low-privilege user | Role assignment; user profile integrity | **Very High (20)** |
| TH-07 | User Management Process (POST/PUT `/users`) | **Repudiation** | A privileged user creates, modifies, or deactivates an account without any audit trail, making it impossible to attribute the action in case of dispute or investigation. | Internal privileged user / Network Admin | Audit traceability; compliance | **Medium High (12)** |
| TH-08 | User Management Data Store (MySQL — `users` table) | **Information Disclosure** | Password hashes or PII, such as email and name, stored in the database are exposed due to SQL injection through unsanitized ORM queries or misconfigured database permissions. | External attacker / malicious insider | Stored credentials; personal data (GDPR) | **High (15)** |
| TH-09 | Role Assignment Process (RBAC middleware) | **Elevation of Privilege** | Absence of authentication middleware allows any authenticated or even unauthenticated caller to invoke privileged operations, such as granting KPI, menu approval, or other protected actions, without a valid role. | Authenticated user / unauthenticated caller | All protected resource operations; operational integrity | **Very High (25)** |
| TH-10 | Role Assignment Process (RBAC middleware) | **Spoofing** | A user crafts or replays a JWT from another role, for example copies a manager token structure with a guessable secret, to spoof a higher-privilege identity. | Authenticated low-privilege user | Identity of privileged users; all protected resources | **High (15)** |
| TH-11 | Menu Management Process (POST/PUT `/menus`) | **Tampering** | An attacker with a valid Supplier token calls PUT `/menus/:id` to modify or force-approve a menu belonging to another canteen, bypassing canteen-scoped authorization. | Authenticated Supplier or low-privilege Canteen Manager | Menu integrity; nutritional accuracy; canteen operations | **Medium High (12)** |
| TH-12 | Menu Management Process (POST/PUT `/menus`) | **Information Disclosure** | `console.log(req.body)` in `MenuController.ts` writes full request bodies, including user input and potentially sensitive nutritional or operational data, to application logs accessible to unauthorized parties. | Internal attacker / unauthorized log reader | Business data; operational details | **Medium High (12)** |
| TH-13 | Order Management Process (POST `/orders`) | **Denial of Service** | Computationally expensive planning and order generation endpoint lacks rate limiting, enabling an attacker to flood it and exhaust server CPU or memory, disrupting weekly planning cycles. | External attacker or malicious authenticated user | Platform availability; weekly planning cycle | **Medium High (12)** |
| TH-14 | Stock Data Store (MySQL — `stock`/`product` tables) | **Tampering** | An attacker submits crafted product or ingredient data via injection or IDOR to manipulate stock records, causing incorrect orders or planning failures. | Authenticated Supplier | Stock integrity; order accuracy | **Medium High (12)** |
| TH-15 | File Upload Process (POST `/applications` — multer) | **Tampering** | An attacker uploads a file with a `.pdf` extension but executable content, such as a webshell or shell script, or embeds path traversal sequences in the filename, achieving server-side code execution or filesystem access. | External candidate / unauthenticated user | Server filesystem; application integrity; other uploaded files | **High (15)** |
| TH-16 | File Storage (`/uploads` — `express.static`) | **Information Disclosure** | `express.static('/uploads')` exposes uploaded supplier documents through predictable URLs, such as `/uploads/suppliers/42/doc.pdf`, allowing any caller to enumerate and download confidential files without authentication. | External attacker / unauthorized user | Confidential supplier documents; GDPR-protected personal data | **Very High (20)** |
| TH-17 | File Storage (`/uploads` — `express.static`) | **Elevation of Privilege** | A logged-in supplier iterates over other suppliers' IDs in download URLs to access and download documents belonging to competitors, exploiting IDOR on the static file server. | Authenticated Supplier | Third-party confidential documents | **High (16)** |
| TH-18 | KPI Calculation Process (GET `/statistics`) | **Tampering** | A Canteen Manager or misconfigured user sends PUT/PATCH requests to alter waste value or organic percentage figures belonging to another canteen, corrupting reporting data. | Canteen Manager with incorrect scope | KPI data; waste reporting; regulatory compliance metrics | **High (12)** |
| TH-19 | KPI Data Store (MySQL — `statistics` tables) | **Repudiation** | A privileged user manipulates KPI or waste data without leaving an audit trail, making it impossible to detect or attribute the tampering during compliance audits. | Internal privileged user | Auditability; regulatory compliance | **Medium High (12)** |
| TH-20 | External Entity → API (HTTP transport) | **Information Disclosure** | The API is served over plain HTTP, exposing credentials and JWTs to network interception on any untrusted network segment. | Network attacker (MITM) | User credentials; JWT tokens; all API payloads | **High (15)** |
| TH-21 | External Entity → API (HTTP transport) | **Denial of Service** | The API accepts JSON bodies without a size limit, allowing an attacker to send extremely large payloads that consume server memory and crash the process. | External attacker | Server availability; all API consumers | **Medium High (12)** |
| TH-22 | Supplier State Process (PUT `/suppliers/:id/quarantine`) | **Tampering** | A quarantined supplier directly calls PUT `/suppliers/:id` with `{"quarantine": false}` to remove their own quarantine status without manager authorization. | Authenticated Supplier | Sanitary integrity; planning safety | **Very High (20)** |
| TH-23 | Supplier State Process (PUT `/suppliers/:id/quarantine`) | **Repudiation** | A Network Admin removes quarantine from a supplier without the action being logged, making it impossible to trace responsibility if contaminated products enter the supply chain. | Internal Network Admin | Audit chain; food safety compliance | **Medium High (12)** |
